# CalisVision PRD — 맨몸운동 자세교정 앱 (1차: 물구나무)

> 원본 소스: `.omc/specs/deep-interview-calisvision-prd.md` (AC-1~AC-16, AC-9b)

## 배경

사용자가 물구나무 영상을 찍으면 전문가 없이도 스스로 자세 결함(바나나 등, 어깨 닫힘, 팔꿈치 굽힘, 골반 전방경사 등)을 확인하고 교정할 수 있는 앱이 없다. CalisVision은 서버·계정·네트워크 없이, 폰 안에서 관절을 추출해 각도를 계산하고 결함을 규칙 기반으로 판정해 보여준다. 1차 범위는 물구나무(정적 홀드) 1개 동작이다.

## 목표

- 갤러리에서 고른 물구나무 영상에서 온디바이스로 33개 관절 키포인트를 추출하고, 4개 각도(전신 정렬·어깨 열림·팔꿈치 펴짐·골반/허리)를 계산해 결함을 판정한다.
- 결과 화면에서 스켈레톤 오버레이 + 각도 수치 + 타임라인 스크럽으로 결함 프레임/구간과 교정 힌트를 확인할 수 있게 한다.
- 촬영 전 "이 결함을 보려면 이 방향에서 촬영하세요"라는 촬영 가이드를 제공한다.
- 100% 오프라인(네트워크 권한 없음) 동작을 보장한다.

## 사용자

- 코치나 헬스장 없이 혼자 맨몸운동(캘리스테닉스)을 연습하는 일반 사용자.
- 물구나무를 배우는 중이며, 자신의 자세가 맞는지 육안 이외의 근거(각도 수치)로 확인하고 싶은 사람.
- 계정·클라우드 동기화가 필요 없는, 개인 기기에서만 쓰는 1인 사용자.

## 범위

- Android 네이티브(Kotlin, Jetpack Compose), 100% 온디바이스 추론, 서버·백엔드 없음.
- 판정 방식: 관절 3점 각도 + 임계값 기반 규칙(ML 분류 학습 없음).
- 관절 추출: MediaPipe Pose Landmarker(33 landmarks), 영상 사후 분석이 1차, 갤러리 선택이 우선(앱 내 촬영은 AC-9b, 후순위).
- 1차 동작: 물구나무(정적 홀드) 1개.
- 임계값 기본값 제공 + 설정 화면에서 사용자 조정 가능.
- 문서 체계(`docs/PRD.md`, `docs/REQUIREMENTS.md`, `docs/decisions/ADR-NNNN-*.md`)와 민감 파일(영상, keystore 등) git 비추적 정책.

## 비범위

- 서버·클라우드 업로드·계정·동기화.
- LLM 기반 자연어 해설(구조상 확장 가능하게 하되 1차 미연결).
- 실시간 카메라 피드백(1차는 사후 분석만).
- 물구나무 외 동작(프론트레버·플란체·머슬업 등)은 이후 버전.
- ML 모델 학습·데이터셋 구축.
- 운동 기록/히스토리 저장, 소셜 기능.
- iOS.

## 핵심 흐름

홈 → 촬영 가이드 → 갤러리 선택 → 분석 → 결과(타임라인+오버레이) → 설정

1. **홈**: 앱 진입점, 분석 시작 버튼.
2. **촬영 가이드**: 결함 확인에 필요한 촬영 방향(측면 등) 안내.
3. **갤러리 선택**: Photo Picker로 물구나무 mp4 영상 선택(1차, 앱 내 촬영은 후순위 AC-9b).
4. **분석**: 온디바이스 프레임 샘플링 → 관절 추출 → 4각도 계산 → 결함 태깅, 진행률 표시.
5. **결과(타임라인+오버레이)**: 영상 프레임 위 스켈레톤 + 4각도 수치 오버레이, 타임라인 드래그로 프레임 스크럽, 결함 구간 시각 표시 + 탭 시 결함명·교정 힌트.
6. **설정**: 4각도 임계값 조정, 재분석 없이 결과에 즉시 반영.

## 성공 기준

- AC-1~AC-16, AC-9b(스펙 기준) 충족.
- 벽 물구나무 기준 영상에서 홀드 구간 전신 정렬 각도가 완화된 기준(≥95% 프레임, [175°,185°])으로 검증됨.
- 비행기 모드에서 전체 분석 흐름이 동작함(오프라인 보장).
