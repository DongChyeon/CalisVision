# ADR-0001: 온디바이스 규칙 기반 판정

## Status
Accepted

## Date
2026-09-26

## Context
물구나무 자세 결함(바나나 등, 어깨 닫힘, 팔꿈치 굽힘, 골반 전방경사)을 서버 없이, 프라이버시를 지키면서, 설명 가능한 방식으로 판정해야 한다. 신체가 담긴 영상은 기기를 떠나지 않아야 한다(스펙 Non-Goal: 서버/클라우드/계정 없음).

## Decision
결함 판정은 3점 관절 각도(부호 = 영상당 고정된 front 기준) + 임계값 규칙(`Range`/`Deviation`)으로 기기 내에서 수행한다. 전신 정렬 각도는 손목–발목 직선 기준 엉덩이 이탈로 정의한다: `θ = 180 + dev`, `dev = signed(180 − angle(손목, 엉덩이, 발목))`, 엉덩이가 손목–발목 선의 front 쪽으로 튀어나오면 +(바나나 등/과신전), 뒤쪽이면 −(파이크). 임계값은 `Deviation(10, 10)`(2026-09-26 사용자 결정). 동일 결함명(예: 파이크)이 여러 규칙에서 겹치거나 간격 ≤ 1 샘플이면 하나의 `FaultSegment`로 병합한다.

### 개정 이력
- 2026-09-26: 초기 제안식(어깨 vertex `손목-어깨-엉덩이`·엉덩이 vertex `어깨-엉덩이-발목` 두 signed angle 중 `|dev|` 큰 값)을 폐기했다. 코드 리뷰에서 어깨 vertex의 −가 "어깨 닫힘"을 뜻해, 어깨 닫힘을 동반한 전형적 바나나(어깨 −20°, 엉덩이 +12°)가 파이크로 판정되고 `어깨 열림` 규칙과 이중 계상되는 문제가 확인되었다. 어깨는 `어깨 열림` 규칙이 전담하고, 전신 정렬은 엉덩이 이탈만 본다.

## Drivers
- 프라이버시(신체 영상 외부 전송 금지)
- 서버 운영 비용 0
- 판정 결과의 설명 가능성(수치로 환원 가능해야 함)

## Alternatives
- 서버 ML 분류 모델
- LLM 기반 자연어 해설
- 온디바이스 학습 분류기(경량 모델 학습)

## Why chosen
라벨 데이터셋이 필요 없고, 모든 판정이 "어떤 각도가 몇 도 벗어났는가"로 설명되며, 스펙의 Non-Goal(서버/LLM 미연결)을 그대로 준수한다.

## Consequences
- 임계값 튜닝이 필요하다(기준 영상 기반 보정).
- 미묘한 결함(예: 견갑 거상)은 3점 각도로 포착하기 어려워 미검출될 수 있다.
- 결함 방향(부호) 정확성이 front 벡터 추정 정확도에 의존한다.

## Follow-ups
- LLM 해설은 `FeedbackReport` 인터페이스에 여지만 남기고 1차에는 연결하지 않는다.
- 전신 정렬(손목–엉덩이–발목) 임계값은 튜닝 영상으로 보정한다.
