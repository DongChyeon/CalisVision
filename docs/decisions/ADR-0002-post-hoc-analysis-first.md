# ADR-0002: 사후 분석 우선

## Status
Accepted

## Date
2026-09-26

## Context
"영상 인식 = 실시간"이라는 초기 가정이 있었으나, 물구나무는 역자세라 방향(0°/180°) 사전 결정, 영상 단위 front 부호 다수결, 프레임 간 스무딩이 필요하다. 언제, 어떤 형태로 결함을 알려줄지 결정해야 한다.

## Decision
녹화된 영상을 사후 분석하는 흐름을 1차로 채택한다. 실시간 카메라 피드백은 후속 확장으로 미룬다.

## Drivers
- 역자세 인식에는 방향 사전 결정·영상 단위 다수결·스무딩이 필요(프레임 단위 실시간 처리로는 불가능)
- 구현 단순성(1인 개발 MVP)
- 검증 용이성(스크럽 UI로 프레임별 결과를 육안 확인 가능)

## Alternatives
- CameraX `LIVE_STREAM` 모드를 이용한 실시간 분석

## Why chosen
사후 분석은 프레임당 지연 제약이 없어 영상 전체를 보고 방향·부호를 안정적으로 결정할 수 있고, 스크럽 UI로 결과를 검증하기 쉽다. 실시간은 매 프레임 즉시 판정해야 해 위 전제(다수결·스무딩)와 충돌한다.

## Consequences
- 운동 중 즉시 교정 피드백은 제공하지 못한다(촬영 후 확인만 가능).
- 영상 전체 디코드/추론 시간이 걸린다(NFR: 30초 영상 ≤ 60초).

## Follow-ups
- 실시간(LIVE_STREAM) 확장 ADR을 별도로 작성하며, 스트림 상황에서의 front 부호 결정 방식을 포함한다.
